## Topics Covered

- **Strings**: Vigenere cipher, anagrams, camel case, character frequency, palindromes, word reversal
- **Arrays/Lists**: Two sum, merge sorted lists, flatten lists, unique elements
- **Matrices**: Transpose, diagonal sort, filter/validate, concentric fill
- **Patterns**: Hourglass, butterfly asterisk
- **Math**: Fibonacci, prime check, digit power sum, denomination optimization
- **Algorithms**: Run-length encoding, streak detection, parenthesis validation
- **OOP**: Country service class with data queries
- **Games**: Rock Paper Scissors

## How to Run

Each file is self-contained. Run any file directly:

```bash
python 01_Vigenere_Cipher_Encryption.py
python 06_Anagrams.py
python 29_Two_Sum.py
```

## Structure

Files are numbered `01` through `30` and ordered with the most impressive/complex problems first, followed by problems sorted by difficulty level (medium then easy).
